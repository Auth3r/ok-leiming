# v1.0.0-beta.8 模组队伍与蓝图流程修复

发布页：[Auth3r/ok-leiming · Beta 8](https://github.com/Auth3r/ok-leiming/releases/tag/v1.0.0-beta.8)。

## 修复内容

- 队员等级识别及八个等级模板统一使用 0.8，移除额外的 0.97 接受门槛和模板高阈值覆盖。
- 模组准备与模组制作共用队伍完成判断。明确有加号空槽仍停止；队伍已配置后直接进入原蓝图选择、确认流程。
- 取消强制九格等级回读，以及蓝图前后、实验确认前对右侧队员列表的重复复核；头像或列表变化不再成为额外阻断。
- 保留页面、空槽和蓝图候选识别；保留原蓝图选择顺序、资源消耗和恢复保护。新一轮会重新确认队伍，不沿用上一轮结果。

## 更新方式

Beta 7 用户可在“关于 → 检查更新”选择 Beta 8 更新。预发布通道需要勾选“检查测试版本”。Beta 6 不包含此更新器，需手动安装完整包。

也可下载 `Leiming-Automation-v1.0.0-beta.8-win-x64.zip`、同名 `.sha256` 及 `release-manifest.json`，核对后完整解压。Beta 7 的标签与资产保留，不覆盖。

## 验证范围

真实失败截图复现 0.823077 分数被旧 0.97 拒绝，新 0.8 接受。生产流程离线回归覆盖两个入口、右侧列表变化与不变、明确未选齐阻断和原蓝图行为；将旧错误重新放回时检查应失败。蓝图界面转换的离线模拟不代表真实游戏测试，也不声称九格 OCR 均已识别成功。

本版未执行跨机器游戏实测。发布包包含对应源码和运行文件哈希；实际构建提交以包内 `release-manifest.json` 为准。更新验收单独记录匿名线上查询、下载校验、安装与重启，不能用源码测试替代。
