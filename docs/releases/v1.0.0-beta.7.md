# v1.0.0-beta.7 首个公开预发布

发布页：[Auth3r/ok-leiming · Beta 7](https://github.com/Auth3r/ok-leiming/releases/tag/v1.0.0-beta.7)。此包从公开仓库的干净源码快照重新构建，实际源码 SHA 和资产摘要见 `release-manifest.json`。私人开发历史和旧 Release 保留在独立私有档案，不导入本仓库。

## 更新内容

- “关于 → 检查更新”匿名读取 `Auth3r/ok-leiming` 的 Releases，普通用户无需 Token。Beta 默认包含测试版，排除草稿和无效标签，只安装更高版本。
- Windows x64 完整包校验 SHA-256、仓库、平台、版本、源码提交及所有运行文件，拒绝配置注入和路径逃逸。
- 安装事务保留旧程序和个人数据，失败时回滚，保留外置数据与 Windows DACL 恢复逻辑。
- 保留 OK 框架二次开发声明、上游版权和全部适用许可证及对应源码。

## Beta 6 用户首次升级

**Beta 6 不包含本次更新器，必须手动下载首个公开 Beta 7 完整包。** 下载 `Leiming-Automation-v1.0.0-beta.7-win-x64.zip`、同名 `.zip.sha256` 和 `release-manifest.json`，核对摘要后完整解压到新的可写目录；不要只复制 EXE，不要覆盖旧配置。按[使用说明](../使用说明.md#手动更新与保留配置)迁移自己的配置。

当前 Beta 7 查询到同版应显示无新版本，不触发安装或降级。没有真实更高已发布版本时，不宣称线上下载、安装、重启及数据保留已经验收。本次只验证发布与更新查询，不启动游戏，也不宣称新包跨机器游戏验收。
