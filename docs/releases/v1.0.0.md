# 镭闪自动化 v1.0.0 正式版

镭闪自动化是面向《镭明闪击》的 Windows 桌面自动化工具，基于 [OK 框架（ok-script）](https://github.com/ok-oldking/ok-script) 二次开发，起步使用 [ok-script-app](https://github.com/ok-oldking/ok-script-app) 模板。当前锁定 `ok-script==2.0.0b7`，通过截图、模板匹配、OCR 和前台输入执行既有任务。

本次将应用版本从 Beta 8 升为 **`v1.0.0` 正式版**，统一版本、下载和使用说明，保留 Beta 8 的业务逻辑及配置行为。版本号升级不会新增任务策略、账号绑定、昵称识别门槛或自动消耗。历史 [Beta 7](v1.0.0-beta.7.md)、[Beta 8](v1.0.0-beta.8.md) 发布说明及对应标签、资产保留。

发布入口：[Auth3r/ok-leiming · v1.0.0](https://github.com/Auth3r/ok-leiming/releases/tag/v1.0.0)。实际公开状态与可下载资产以 Releases 为准；源码提交、EXE 和 ZIP 的身份以该包的 `release-manifest.json` 及哈希为准。

## 主要功能

- **日常任务：**理财基金、黑盾领取及派遣、暗涌 04-3、干火 ST-7、猎金 ER-2、每日奖励；可单项执行或按保存的开关运行完整路线。首次七项开关开启，打开软件不会自动开始。
- **黑盾派遣：**普通委托沿用界面顺序及已有条件核对；四人同战术固定筛选乌斯怀亚，从左至右、从上至下选择前四名，逐人确认选中及人数变化。职业种类数 2 沿用普通规则。
- **模组制作：**军工、一致、先攻配置，准备、循环制作、继续当前模组及制作记录浮窗；旧地联合保留兼容入口。保留 Beta 8 队伍判断修复：明确空槽仍停止，配齐后直接进入蓝图，不再强制九格等级回读或重复核对右侧列表。
- **肉鸽：**720P 原生 WGC 面板、既有 4K 路径、循环次数、当前页面接管和悬浮窗；既定刷取路线为第二层悬赏后结算。
- **维护结束提醒：**按设置间隔检查维护状态，确认进入主界面后提醒并停止，不自动接着运行日常。
- **控制与诊断：**F7 暂停／继续、F8 停止，游戏连接预览、本地问题报告及运行／构建身份记录。

## 系统要求与安装

1. 使用 **Windows x64**；不支持 macOS / Linux。主要已有游戏验证环境为 **1280×720 客户区、窗口化、150% 系统缩放**。保留 4K 与自动识别路径，不代表所有 DPI、电脑和账号均已验收。
2. 下载 `Leiming-Automation-v1.0.0-win-x64.zip`、同名 `.zip.sha256` 和 `release-manifest.json`。公开下载无需 GitHub Token；GitHub 的 Source code 压缩包不是可运行便携包。
3. 核对 ZIP 的 SHA-256，在当前机器已存在、空间充足的可写磁盘中新建目录，**完整解压**。保留原目录，不在压缩包预览中启动，也不只复制 EXE。
4. 双击 `Leiming-Automation.exe`，核对窗口版本、提交号和 manifest。便携包自带运行依赖，无需另装 Python；源码开发使用 Python 3.12 x64，执行仓库的 `Setup.cmd` 和 `Start.cmd`。
5. 手动启动并登录 `Warp Knights.exe`，检查“截图方式 → 游戏连接与问题报告”的窗口及预览，再核对任务开关、扫荡次数、制作配置与数量，手动开始。运行会使用游戏前台，保持窗口可见。

完整操作见[使用说明](../使用说明.md)。

## 从 Beta 升级与更新通道

- **Beta 7／8：**正式版发布后，可在“关于 → 检查更新”选择 `v1.0.0`。先停止任务；安装器校验 ZIP 和全部运行文件，保留个人配置与数据、备份旧目录后替换并重启。启动失败时按现有机制恢复旧版。
- **Beta 6：**旧包缺少本项目更新器，必须手动下载完整新包。不要只替换 EXE。
- **手动升级：**关闭旧版并备份整个目录，将新版解压到独立新目录；首次启动前迁入自己的 `settings.json`、`config_version.json`、完整 `configs/` 和已有 `config-backups/`。保留旧日志与恢复记录；有未完成模组时先保留现场，跨版本同件接续尚未完整验收。具体步骤见[配置迁移说明](../使用说明.md#手动更新与保留配置)。
- **正式版通道：**`v1.0.0` 默认仅检查正式发布；手动勾选“检查测试版本”后才包含 Beta／RC。草稿不参与更新，同版和低版本不会安装。检查失败不会阻止软件正常启动；只读目录可使用手动升级。

## 已知限制与验证边界

- 旧地联合在当前游戏环境不能正常制作；军工／一致有历史实机记录，先攻随机后半程、全部恢复组合和完美成品均不作保证。模组配队由使用者完成。
- 肉鸽既定路线不等于五层全通，全部随机事件与长期无人值守仍未完整验收。维护提醒的真实开服路径需要对应场景。
- 游戏更新、HDR／滤镜、界面布局、窗口大小及权限变化可能影响识别。OCR 读空仅表示识别不确定，不代表次数为零或任务已完成；结果不明时保留现场，勿重复派遣、扫荡、刷新或确认来补证。
- 不自动付费、购买次数或补充体力；已有配置、材料消耗及任务开关行为保持不变。换号后需以当前画面确认状态，不能沿用上一账号结果。
- 正式版本号不替代验收。本说明不宣称新 EXE 已完成完整日常、四人同战术、多机器、多账号或全部 DPI 的实机测试；源码回归、构建校验、EXE 启动、真实线上升级和游戏流程应按本次实际记录分别说明。历史 Beta 结果及模拟测试不能代替当前包结果。

遇到问题先停止相关任务，保留原始日志和截图，通过[本项目 Issues](https://github.com/Auth3r/ok-leiming/issues)反馈版本、构建提交、分辨率、DPI、复现步骤和错误提示。问题报告只在本地生成；发送前检查并遮挡副本中的无关个人信息，保留原件。
